Jjigeo Support

Write to yuppie0041@gmail.com. Jjigeo collects no usage information, so it helps if you describe which screen you were on and what happened. Please don't send photos that contain personal information.

The details read from my photo are wrong

Jjigeo reads text on your phone. Blurry or tilted photos, handwriting and glare can cause misreadings, which is why there is always a review screen before saving. Tap a value to correct it, or use the quote button to pick from the text that was read. When a value is uncertain, Jjigeo asks you to confirm it first.

It doesn't say the event was saved to my calendar

Jjigeo only opens the editing screen of your calendar or contacts app; you press Save there yourself. Jjigeo cannot tell whether it was actually saved, so it records only that the screen was opened.

Moving to a new phone

Create a file with Settings → Export all data, then load it on the new phone with Settings → Import data. You can set a password when exporting; if you forget it, that file cannot be opened. Jjigeo has no account, so nothing moves automatically.

It says my saved records can't be opened

Records are locked with a key only this phone knows. If you just restarted the phone, unlock the screen once and tap "Try again". If it still won't open, check whether you have an exported file, then you can choose "Delete everything and start over". We do not hold the key and cannot restore your records.

Photos with sensitive information

Use "Hide" on the photo screen to black parts out. Jjigeo marks lines that look like ID, card or bank account numbers, but it can miss some, so please check yourself. Hidden parts are not kept in the record.
